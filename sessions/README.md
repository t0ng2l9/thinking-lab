# 训练记录

这个目录放**真实训练记录**，用来给使用者一个"填满之后长什么样"的参照。

命名：`NNN-主题.md`（例：`001-distribution-before-output.md`）

## 关于已公开的示例

`sessions/001-*.md` 是一次真实训练，已脱敏：

- 平台名、项目名、具体数字做了泛化
- 推理过程、自伐内容、修正结论、暴露的错误编号全部保留原样
- 包括一处**教练自己的错误**（阶段一未先问目的），保留下来是因为审计栏不能只出现在模板里

## 个人记录不要放这里

除了 001 这份示例，其余训练记录请留在本地或私有仓库。`.gitignore` 已把它们排除，只放行 `001-*` 与 `README.md`。

理由：训练记录里有大量真实处境、错误和分数，写的时候要敢写真话。一旦知道会被公开，人会不自觉地美化——那会直接污染诊断。
