# 训练规则

一次训练 = 四阶段 + 六层模型自查。两者是**正交**的：四阶段管时间安排，六层管分析质量。

---

## 一、四阶段机制（约 30 分钟）

| 阶段 | 时长 | 内容 | 纪律（违反即作废本次训练） |
|---|---|---|---|
| 一、独立思考 | 5 min | 由**你**选题，不查资料先写下判断 | 教练不替你出题；仅当你没题时，给两个**不同方向**的候选并说明各自的张力 |
| 二、结构拆解 | 10 min | 识别关键变量、变量关系、初步因果链 | 由你列变量，教练只追问遗漏，不补全 |
| 三、反方论证 | 10 min | 最强反对意见、隐含假设、反例、替代解释 | 教练给反方；你必须正面回应，不许绕开 |
| 四、总结抽象 | 5 min | 提炼规律、迁移到其他领域、记录本次暴露的问题 | 写成一句可复用的模型 |

### 阶段之间的两道自检（可选但强烈建议）

**阶段二之前 —— 前置三问**，各写一行，写不出来就别开始推：

```
1. 这题里最重要的那个词，我的定义是什么？
2. 我要拿什么指标检验它？这个指标能被证伪吗？
3. 我的结论说在哪一层？我的证据在哪一层？两层一样吗？
```

这三问分别拦三类高频错误：概念未定义就开推、指标与假说不匹配、层次混淆（见 [`errors.md`](errors.md) 的 E-06 / E-13 / E-08）。

**阶段三之前 —— 自己先打自己两条**：

```
在教练给反方之前，先写两条「我这个结论最可能在哪儿错」。
写不出来也要写，宁可写错。这一栏才计分。
```

理由：不主动构造反例的人，练一百次也不会开始构造——因为流程里从来没有给反例留位置。

## 二、六层思维模型（分析质量检查表）

每层是一个必答问题。**该层没过，不允许进入下一阶段。**

| 层 | 要问的问题 | 落在哪一阶段 | 不合格的样子 |
|---|---|---|---|
| 1 信息获取 | 哪些是事实，哪些是传闻？出处是什么？ | 阶段一末尾 | 把传闻当事实写进判断 |
| 2 问题定义 | 真正值得解的是哪个问题？我是不是在解一个被喂给我的问题？ | 阶段一 | 题面没定义清楚就开答 |
| 3 结构拆解 | 拆成政治 / 经济 / 技术 / 心理几块，缺哪块？为什么缺？ | 阶段二 | 只给一条线 |
| 4 机制推理 | 变量靠什么机制连起来？换掉这个机制，结论还成立吗？ | 阶段二 | 只给相关，不给机制 |
| 5 多角度检验 | 反例、竞争性解释、利益冲突、证据缺口在哪？ | 阶段三 | 只有一个解释 |
| 6 抽象迁移 | 能提出什么跨领域规律？失效边界在哪？ | 阶段四 | 结论只对这一个案例成立 |

## 三、五能力与九维度（为什么评分是 8 维）

训练目的本身是五项能力：

1. **结构化思考**：从具体事件逐步抽象到制度、国家利益、资本权力
2. **多层次分析**：不只看事件，还看制度、利益、激励和长期后果
3. **因果推理**：从现象推导机制，而不是罗列信息
4. **抽象能力**：从具体人物和事件中提炼普遍规律
5. **反向思考**：不只问好处，还问副作用

九项操作维度是它们的可操作展开（结构化思考 / 第一性原理 / 系统思维 / 因果推理 / 博弈论 / 概率思维 / 批判性思维 / 元认知 / 抽象迁移）。

而实际评分用的是 **8 维**（见 [`scoring.md`](scoring.md)）。8 维不等于 5 能力，它是一次**有偏斜的重写**——这份偏斜必须知道，写在 [`blindspots.md`](blindspots.md)。

其中两处最容易练偏：

- **「多层次分析」在 8 维里没有独立项**，被摊进「多角度」；而「多角度」只数「有几条机制」，不判断层次是否递进。
- **「反向思考」被误并入「反方论证」**，但两者不是一回事：

| | 问什么 | 性质 |
|---|---|---|
| 反向思考 | 这个决定会产生什么副作用？ | 机制层，事前推演 |
| 反方论证 | 你这个结论哪里站不住？ | 辩论层，事后审查 |

所以评分之外，每轮另记两个**不计分观察项**：反向思考、多层次递进（见 [`blindspots.md`](blindspots.md)）。

## 四、选题范围

优先领域：人工智能与计算机科学 / 心理学与认知科学 / 国际政治与地缘经济 / 经济学与资本市场 / 科技产业与商业竞争 / 社会学与哲学。

定期插入跨学科问题，训练迁移。

好题目的三个特征：

1. 反直觉（答案不是常识的复述）
2. 有机制可拆（不是纯价值判断）
3. 你现在的判断可能是错的

示例：

- 为什么一个国家越重视技术自主，反而可能越依赖其他国家？
- 为什么科技巨头越来越需要政府？
- 为什么经济增长不一定带来社会幸福？
- 为什么 AI 可能提高生产效率，却不一定提高人的创造力？

## 五、最重要的规则

**禁止**：

```
提问 → AI 直接回答 → 阅读 → 结束
```

**执行**：

```
提问 → 我独立思考 → AI 追问 → 我修正 → AI 给反例 → 我重新论证 → 总结
```

最终目标是不依赖 AI 也能完成复杂分析。四个跃迁阶段：

1. AI 辅助思考：借助 AI 理解复杂知识
2. AI 协同思考：自己提假设，AI 帮助检验
3. 独立思考：先建自己的框架，再用 AI 补充
4. 独立研究：发现未解问题、设计研究、形成原创结论

衡量标准不是读了多少，而是**三个月后能否独立分析一个过去无法理解的复杂问题**。

验收点：提出好问题的能力 / 建立解释模型的能力 / 在证据推翻自己时修改观点的能力。

## 六、推荐阅读（每个阶段配一本）

书是训练对应能力的工具，不是知识补给。读完只写一句：**这本书改变了我哪个判断。**

| 书 | 定位 | 什么时候读 | 配哪个训练 |
|---|---|---|---|
| 《清醒思考的艺术》 | 入门 | 第 1 月 | 配错误档案，给自己的错误归类 |
| 《系统之美》 | 重点 | 第 2 月 | 反馈回路、存量流量，配系统思维 |
| The Scout Mindset | 重点 | 全程 | 反方论证、元认知——找真相而非守立场 |
| The Book of Why | 进阶 | 第 3 月 | 因果推断，配从相关到因果 |
