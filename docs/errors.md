# 认知错误档案

训练的价值不在于答对，而在于**让同一个错误不再犯第三次**。

做法：给错误编号 → 记录本次的具体表现（原话）→ 记复发次数 → **复发 ≥ 2 次的，进入下一轮训练的重点观察项**。

---

## 13 类可命名的错误

清单本身比记录表更值钱：有了名字，你才能在犯错的当下认出它。

| 编号 | 错误类型 | 典型表现 |
|---|---|---|
| E-01 | 相关当因果 | 两件事同时发生，就断言其中一个导致另一个 |
| E-02 | 单一解释 | 只保留一个原因，忽略并存机制 |
| E-03 | 选择性证据 | 只找支持自己判断的案例 |
| E-04 | 过度推广 | 用个别案例推出普遍规律 |
| E-05 | 假设当事实 | 把未验证的前提直接写进结论 |
| E-06 | 概念漂移 | 同一个词在论证中途换了含义 |
| E-07 | 忽略反事实 | 不追问「如果不这样做会怎样」 |
| E-08 | 尺度混淆 | 把个体动机直接套到国家 / 组织层面 |
| E-09 | 结论先行 | 先有立场，再倒推理由 |
| E-10 | 不可证伪 | 提出的判断无论发生什么都能自圆其说 |
| E-11 | 循环论证 | 用结论的定义去解释结论的成因 |
| E-12 | 用结果解释结果 | 拿事后的后果当评价事前判断的指标 |
| E-13 | 指标与假说不匹配 | 用总量指标（占比）检验结构假说（集中度） |

### 三组最容易撞的

- **E-06 / E-13 / E-08**：都源于「先推演、后定义」。前置三问（见 [`rules.md`](rules.md)）就是拦这三个。
- **E-11 / E-12**：都源于「拿结果当原因」。特征是句子里出现「因为它离不开，所以它依赖」这类同义反复。
- **E-01 / E-03 / E-07**：都源于只朝一个方向找证据。先自造反例（见 [`rules.md`](rules.md)）能拦一层。

## 记录表

| 日期 | 错误编号 | 本次具体表现（原话） | 触发情境 | 纠正动作 | 复发次数 |
|---|---|---|---|---|---|
| YYYY-MM-DD | E-xx | 当时的原话，不要润色 | 被问到什么的时候犯的 | 下次遇到同类情形该做什么 | 1 |

规则：

1. **表现栏记原话**。事后改写成「我当时应该想……」会污染诊断。
2. **一次犯多条就记多行**，不要合并成「逻辑不清」。
3. **复发次数是核心指标**。同一编号出现第 2 次，就写进下一轮的重点观察项；出现第 3 次，说明前面的纠正动作无效，要换方法而不是加练。
4. 新出现的错误类型可以加 E-14、E-15——**归类本身就是在训练**。

## AI 出错记录（别省这一栏）

单向批评会把训练变成「我交作业、AI 批改」。这一栏的存在，是把训练变成双向的。

| 日期 | 教练的原话 | 属于哪类病 | 我是否指出 | 处理结果 |
|---|---|---|---|---|
| YYYY-MM-DD | 摘录原句 | 见下三类 | 是 / 否 | 它承认 / 它反驳 / 它搪塞 |

必查三类病：

1. **相关当因果**：把同时出现说成因果
2. **推测当事实**：把没证实的机制推测说得像定论
3. **单案例推一般**：用一个例子支撑普遍结论

补充两类常见越权：

- **越权**：你只是想讨论，它却直接进入训练流程并给你出题
- **代劳**：它替你完成了本该你做的迁移或总结

> 这一栏长期为空，通常不是 AI 没错，而是你没在审它。
